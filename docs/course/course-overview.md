# 課程概觀

本頁介紹課程學習方式與整體脈絡。第一版先提供課程影片、中文字幕、繁體中文摘要、閱讀材料與詞彙表；題庫與 Lab 實作內容會納入後續版本規劃。

## 學習目標

- 建立 IBM Z 與 z/OS 在企業核心系統中的整體認識。
- 理解大型主機硬體、作業系統、虛擬化、安全與啟動流程之間的關係。
- 熟悉後續單元會反覆出現的術語，例如 LPAR、HMC、SE、Sysplex、IOCDS 與 IPL。
