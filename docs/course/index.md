## 建議學習方式

1. 先閱讀「課程概觀」，了解 IBM Z 與 z/OS 在企業核心系統中的定位。
2. 依序完成「大型主機環境」、「大型主機基礎架構」與「大型主機安全」三個單元。
3. 每支影片先看完一次，再回到影片下方摘要確認學習重點與重要術語。
4. 遇到不熟悉的 IBM Z 名詞時，搭配詞彙表查閱原文術語與繁體中文說明。

## 學完後你會理解

- 大型主機與一般伺服器在設計目標、可靠性與工作負載上的差異。
- z/OS 如何管理硬體資源、應用程式、資料存取、安全控制與系統啟動。
- LPAR、HMC、SE、Sysplex、IOCDS、Crypto Express 與 IPL 等入門術語的基本脈絡。
