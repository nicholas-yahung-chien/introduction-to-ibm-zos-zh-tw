# IBM Z 組態設定

> 來源活動：https://learn.ibm.com/mod/page/view.php?id=96630

本閱讀頁提醒學習者參考 IBM Z 伺服器安裝與組態設定的快速參考資料。雖然這部分不作為第一版題庫範圍，但理解新伺服器安裝前需要規劃哪些項目，對大型主機基礎架構學習很有幫助。

## 學習重點

- IBM Z 組態設定需要在安裝前先規劃硬體、邏輯分割區、I/O 與管理介面。
- 新伺服器導入不是單一動作，而是一組跨硬體、韌體、作業系統與營運流程的規劃工作。
- 課程中的 HMC、SE、LPAR、IOCDS 與 Sysplex 等概念，都會在實際組態規劃中連在一起。

## 建議閱讀方式

把這份材料視為「建立大型主機環境時需要考慮什麼」的索引。第一輪學習時先了解規劃面向，等熟悉影片中的術語後，再回頭對照實際設定步驟。
