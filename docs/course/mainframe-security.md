# 大型主機安全

本單元介紹 z/OS 安全概念、交易層級安全、Crypto Express、IOCDS、啟動設定檔與 IPL 流程。

## 本章目標

- 理解 z/OS 安全如何涵蓋存取控制、資料保護與可用性。
- 說明 IBM Z 如何透過硬體與軟體支援加密與金鑰管理。
- 認識 IOCDS、啟動設定檔與 IPL 在系統初始化中的角色。
