## Fabric

在光纖通道技術中，路由結構（例如交換器）接收尋址資訊並路由到適當的目的地。一個結構可以由多個交換器組成。當多個光纖通道交換器互連時，它們被稱為級聯。

## Failback

與修復後的故障轉移中的叢集恢復有關。另參見故障轉移。

## Failover

涉及當儲存系統中的另一個叢集發生故障時將所有控制權轉移到單一叢集的過程。另參見叢集和故障復原。

## Fast File System (FFS)

FFS 發明了柱面組，它將磁碟分成更小的區區塊，每個組都有自己的索引節點和資料區塊。

## Fast write

以快取速度進行的寫入操作，不需要立即將資料傳輸到磁碟機。子系統將資料直接寫入快取、非揮發性儲存或兩者。然後資料可用於降級。快速寫入操作減少了應用程式必須等待 I/O 操作完成的時間。

## Feature Code (FC)

標識特定可訂購選項並由服務人員用來處理硬體和軟體訂單的代碼。各個選用功能均由唯一的功能代碼標識。

## Fibre Channel (FC)

基於 ANSI 光纖通道標準的資料傳輸架構，支援全雙工通訊。 DS8000 系列透過其光纖通道介面卡支援光纖電纜上的資料傳輸。另參見光纖通道協定和光纖通道標準。

## Fibre Channel Arbitrated Loop (FC-AL)

光纖通道標準的實現，使用環形拓撲進行通訊結構。參見美國國家標準協會 (ANSI) X3T11/93-275。在此拓撲中，兩個或多個光纖通道端點透過環形介面互連。此拓撲直接將儲存系統連接到開放系統主機，無需透過光纖交換器。

## Fibre Channel Connection (FICON)

專為 IBM 大型電腦和周邊裝置設計的光纖通道通訊協定。它使用 FICON z/OS 通道直接或透過 FICON 交換器將儲存系統連接到一台或多台 IBM Z 主機。

## Fibre Channel Protocol (FCP)

光纖通道通訊中使用的協議，具有五層，定義光纖通道連接埠如何透過其實體鏈路進行互動以與其他連接埠進行通訊。 FCP（光纖通道協定）支援存取小型電腦系統介面（SCSI）週邊裝置。

## Fibre Channel Standard (FCS)

電腦外圍介面的 ANSI 標準。 I/O 介面定義了透過序列介面進行通訊的協議，該介面將附加單元設定到通訊結構。該協定有兩層。 IP層定義了基本的互連協定。上層支援一種或多種邏輯協定（例如，用於SCSI命令協定的FCP和用於IBM Z命令協定的SBCON）。參見美國國家標準協會 (ANSI) X3.230-199x。

## Fibre Channel Switched Fabric (FC-SF)

光纖通道標準的一種實現，透過光纖交換器將儲存系統連接到一台或多台開放式系統主機，或連接一台或多台在光纖通道協定 z/OS 通道上執行 LINUX 的 z/OS 主機。

## FICON

參見光纖通道連接。

## FiconNet

在 DS8000 儲存管理 GUI 中，偽主機圖示上的標籤，代表使用 FICON 協定的主機連接，但在 DS8000 系列上未完全定義。另參見偽主機和任意存取模式。

## Field Replaceable Unit (FRU)

當任何一個組件發生故障時，需整體更換的組件。在某些情況下，現場可更換單元可能包含其他現場可更換單元。

## File Transfer Protocol (FTP)

TCP/IP 是一種應用程式協議，用於在主機之間傳輸檔案。另參見傳輸控制協定/網際網路協定。

## Firewall

防止未經授權連接到電腦或資料儲存系統。保護通常採用網關伺服器上的軟體形式，授予符合授權標準的使用者存取權限。

## Fixed Block Architecture

邏輯裝置的體系結構，指定裝置上邏輯資料單元的格式和存取機制。邏輯資料單元是區塊。裝置上的所有區區塊都具有相同的大小（固定大小）。子系統可以獨立存取它們。

## Flag parameter

一個整數標誌，指示是否需要對提供的項目名稱或編號執行匹配。

## Flash cards

是高 IOPS（每秒輸入/輸出操作數）級企業儲存裝置，導向第 0 層、I/O 密集型工作負載應用程式，可以使用高階的快速存取儲存。

## FlashCopy

FlashCopy 是各種 IBM 儲存裝置支援的 IBM 功能，幾乎可以即時建立整個邏輯磁碟區或資料集的時間點快照副本。這些副本可立即用於讀取和寫入存取。

## FlashCopy relationship

FlashCopy 來源磁碟區和 FlashCopy 目標磁碟區的映射，允許將來源磁碟區的時間點副本複製到目標磁碟區。 FlashCopy 關係從您啟動 FlashCopy 作業時一直存在，直到儲存系統將所有資料從來源磁碟區複製到目標磁碟區，或直到您刪除 FlashCopy 關係（如果該關係是持久的）。

## FlashCopy SE

DS8880 系列的可選功能，可根據「需求」配置儲存空間，並在 FlashCopy 關係的生命週期內僅使用所需數量的磁軌來寫入變更的資料。

## Flash Raid Adapter

管理使用光纖通道協定進行主機系統連接的外部 I/O 介面的介面卡。它也用於在儲存系統之間複製資料。

## Flexible Service Processor (FSP)

提供診斷、初始化、設定、執行時錯誤偵測和修正的韌體。 FSP 是將受管系統連接到硬體管理控制台 (HMC) 的元件。

## Floating spare

當 DDM 發生故障並且其中包含的資料被重建到備用磁碟上時，當更換磁碟時，替換磁碟將成為備用磁碟。資料不會遷移到另一個DDM，例如故障DDM所佔用的原始位置的DDM。 DS8000 微代碼將這個想法更進一步。它可能會選擇允許熱備件保留在已移動的位置，但它也可以選擇將熱備件遷移到更好的位置。這樣做是為了更好地平衡 DA 對、環路和磁碟盒之間的備用零件。

## Frame

## FREE command (In UNIX)

使用 FREE 命令釋放（取消配置）先前指派的不再需要的資料集或分層檔案系統 (HFS) 檔案。您也可以使用此命令變更 SYSOUT 資料集的輸出類別以刪除屬性列表，並變更使用 ALLOCATE 命令指定的資料集處置。任何一次可以配置給您的資料集都有最大數量。

## Full Disk Encryption (FDE)

是對磁碟機上的所有資料進行加密，包括加密可啟動作業系統分割區的程式。它由製造期間安裝在驅動器上的磁碟加密軟體或硬體或透過附加軟體驅動程式執行。 FDE 將所有裝置資料轉換為只有擁有解密加密資料金鑰的人才能理解的形式。身份驗證金鑰用於反向轉換並使資料可讀。 FDE 可防止未經授權的磁碟機和資料存取。

## Fully provisioned

磁碟區容量在建立磁碟區時完全配置。在這種情況下，完全設定的磁碟區所連接的主機擁有全部容量，因此會消耗後端系統中未使用的儲存空間。

## Function Modification Identifier (FMID)

用於標識單獨的產品或產品功能的標識符。

## Fuzzy copy

全域複製特徵的功能，其中稍後在輔助邏輯磁碟區上執行對主邏輯磁碟區的修改。不嚴格保持原來的更新順序。另參見全域副本。
## Function key (ISPF)

ISPF panel 下方顯示的 PF key 功能提示，例如 `F1=Help`、`F3=Exit`、`F7=Backward`、`F8=Forward`、`F9=Swap`。Function key 是 ISPF 操作的基本導航方式，不同 panel 可有不同 key definition，實際功能應以當前畫面下方提示與 `F1` help 為準。
