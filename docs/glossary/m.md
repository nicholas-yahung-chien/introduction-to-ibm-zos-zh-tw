# IBM Z 詞彙表：M

[返回詞彙表索引](./)

## Machine code

由電腦中央處理單元 (CPU) 直接執行的一組指令。

## Mainframe

電腦，通常位於電腦中心，具有廣泛的功能和資源，其他電腦可以連接到該電腦，以便它們可以共享設施。 (T)

## Management console

參見硬體管理控制台。

## Memory

也稱為儲存，是一種由電腦組件和用於保留數位資料的記錄媒體組成的技術。它是電腦的核心功能和基本組成部分。

## Multiple Virtual Systems (MVS)

是 System/370 和 System/390 IBM 大型主機上最常用的作業系統。
