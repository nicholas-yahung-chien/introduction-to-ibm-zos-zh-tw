# IBM Z 詞彙表：H

[返回詞彙表索引](./)

## HACMP

參見高可用性叢集多重處理。

## Hard disk drive

1) 儲存伺服器內的儲存介質，用於維護儲存伺服器所需的資訊。 2) 用於電腦的大容量儲存介質，通常可用作固定磁碟（例如個人電腦的系統單元或個人電腦外部磁碟機中使用的磁碟）或可移動盒式磁帶。

## Hardware

是電腦系統物理部分的集合。

## Hardware Configuration Definition (HCD)

從單一互動式介面定義軟體和硬體的 I/O 設定。 HCD 用於建立輸入/輸出定義檔 (IODF)。

## Hardware Management Console (HMC)

控制受管系統的系統，包括邏輯分區的管理和容量按需升級的使用。 HMC 使用服務應用程式與託管系統進行通訊以偵測和整合訊息，然後將訊息傳送到 IBM 進行分析。

## Hardware service manager

IBM i 主機上的一個選項，使使用者能夠顯示和使用系統硬體資源以及偵錯輸入輸出處理器 (IOP)、輸入輸出介面卡 (IOA) 和裝置。

## HCD

參見硬體設定定義。

## hdisk

儲存空間的 AIX 術語。

## Heartbeat

DS8000 儲存系統定期發送的狀態報告。服務提供者使用此報告來監控回撥流程的運作狀況。另參見呼叫主頁和遠端技術援助資訊網路。

## HELP command (In UNIX)

使用 HELP 命令可以獲得有關命令和子命令的功能、語法和操作數的資訊，以及有關某些訊息的資訊。

## Hierarchical storage management

儲存管理軟體（例如 IBM Spectrum Control 或資料設施儲存管理子系統/MVS (DFSMS/MVS)）中的一項功能，可根據儲存管理員設定的政策自動管理可用空間。

## Hierarchical File System (HFS)

HFS 是 Apple Inc. 開發的專有檔案系統，用於執行 Mac OS 的電腦系統。

## High Availability Cluster Multi-Processing (HACMP)

是 PowerHA（高可用性）的舊術語。 PowerHA是一款特殊的軟體，它可以提供冗餘和高可用性，以滿足系統發生故障時的需求，讓另一個系統立即接手。

## High Performance FICON for IBM Z (zHPF)

是 FICON 通道架構的增強。您可以透過將 zHPF 與 FICON 通道、z/OS 作業系統和控制單元結合使用來減少 FICON 通道 I/O 流量影響。 zHPF 允許控制單元將多個命令的資料流回單一資料傳輸部分，用於由各種存取方法啟動的 I/O，從而提高小區塊傳輸的通道吞吐量。

## High-Performance Flash Enclosure (HPFE)

包含快閃儲存卡，透過 PCIe 連接到 I/O 機櫃。

## Hipersocket

大型主機 HiperSockets 是一種在中央處理器複合體中提供高速 TCP/IP 連接的技術。它消除了不同 LPAR 中執行的伺服器之間的任何實體佈線或外部網路連接的需要。

## Hop

交換器間連接。跳數是特定資料區區塊在來源和目標之間遍歷的連接數。例如，資料透過電線從一個集線器傳輸到另一個集線器會經過一跳。

## Host

參見主機系統。

## Host Adapter (HA)

儲存伺服器的一種實體子單元，能夠連接到一個或多個主機 I/O 介面。

## Host name

網路中機器的網際網路位址。主機名稱可以作為附加主機系統的完全限定網域名稱（例如 mycomputer.city.company.com）或作為完全限定網域的子名（例如 mycomputer）在主機定義中輸入。另參見主機系統。

## Host processor

控制全部或部分使用者應用程式網路的處理器。在網路中，資料通訊存取方法所在的處理單元。另參見主機系統。

## Host system

連接到 DS8000 系列的電腦，可以是大型主機（例如 IBM Z）或開放系統類型。主機透過 ESCON、FICON 或光纖通道介面連接。

## HMC

參見硬體管理控制台。

## HTTP

參見超文本傳輸協定。

## Huffman Coding

是一種無損資料壓縮演算法。這個想法是為輸入字元配置可變長度代碼，所配置代碼的長度是基於相應字元的頻率。

## HyperPAV

可選許可功能，可與並行存取磁碟區 (PAV) 功能結合使用。 IBM HyperPAV 將磁碟區與別名位址或指定的基本邏輯磁碟區號關聯。當主機系統請求 IBM HyperPAV 處理並且啟用該處理時，邏輯子系統上的別名將在具有給定路徑組 ID 的所有邏輯路徑上置於 IBM HyperPAV 別名存取狀態。 IBM HyperPAV 僅在 FICON 通道路徑上支援。

## HyperSwap

HyperSwap 技術使主機能夠將應用程式的 I/O 操作透明地切換到輔助 Metro Mirror 磁碟區，前提是主機和輔助儲存子系統之間存在實體連接。這使得能夠從單一站點或從地鐵距離內的多個位置提供連續操作。透過實作 HyperSwap，可以承受磁碟故障和維護功能，而不會對應用程式服務造成任何中斷。

## Hypertext Transfer Protocol (HTTP)

是分散式、協作和超媒體資訊系統的應用協定。 HTTP 是萬維網資料通訊的基礎。

## Hypervisor

是建立和執行虛擬機器的電腦軟體、韌體或硬體。虛擬機器管理程式執行一個或多個虛擬機器的電腦稱為主機，每個虛擬機器稱為訪客機。管理程式為客戶作業系統提供虛擬操作平台並管理客戶作業系統的執行。
