## CDS

參見耦合資料集。

## Central Processing Unit (CPU)

是電腦处理指令的主要组件。它執行作業系統和應用程式，並不斷接收來自使用者或活動軟體程式的輸入。它處理資料並產生輸出，該輸出可以由應用程式儲存或顯示在螢幕上。

## Central Processor (CP)

電腦的一部分，包含用於指令執行、初始程式載入和其他機器操作的排序和處理設施。

## Central Processor Complex (CPC)

指硬體的實體集合，包括主記憶體、一個或多個中央處理器、計時器和通道。

## CF

參見耦合設施。

## Channel

通道子系統的一部分，用於管理通道子系統和一組控制單元之間的單一 I/O 介面。

## Channel Path Identifier (CHPID)

由通道路徑ID或CHPID表示的通道代表實際的通訊路徑。 CHPID 是促進 CPC 和外部裝置之間通訊的句柄。 CHPID 必須是唯一的，因為它表示 CPC 的唯一通訊路徑。通道子系統內允許的最大 CHPID 數量為 256。通道可以在 LPAR 之間共用。 CHPID 與實體連接埠或主機內部定義的內部連線相關聯。有效的 CHPID 的十六進位範圍是從 X'00' 到 X'FF'。

## CICS

參見客戶資訊控制系統。

## Configure

在儲存中，透過儲存系統為此功能提供的使用者介面來定義輸入/輸出子系統的邏輯和實體裝置、選用功能和程式產品。

## Console

伺服器的使用者介面，例如個人電腦上提供的介面。另參見硬體管理控制台。

## Control unit

1）協調和控制一個或多個輸入/輸出裝置的操作，並使這些裝置的操作與整個系統的操作同步的裝置。 2) 對於IBM Z，具有FICON或OMI介面的儲存伺服器。控制單元將本機裝置介面適配為 IBM Z Systems 主機系統支援的 I/O 介面。 3) 儲存系統的一部分，支援透過 ESCON、FICON 或 OMI 介面連接類比計數關鍵資料裝置。另請參見叢集。

## Couple Data Set (CDS)

耦合資料集提供了系統綜合體中每個系統都需要可見的中央共用資料儲存庫。 CDS 以及對其中資料的所有存取均由 XCF 管理。

## Coupling Facility (CF)

是一個允許多個處理器存取相同資料的電腦硬體。平行系統綜合體依賴於一個或多個耦合設施 (CF)。

## CP

參見中央處理器。

## CP Assist for Cryptographic Function (CPACF)

是一組提供改進效能的加密指令。

## CPC

參見中央處理綜合體。

## CPU

參見中央處理單元。

## Cross-System Coupling Facility (XCF)

是 z/OS 的一個元件，用於管理系統綜合體中的應用程式之間的通訊。應用程式可能位於同一系統或不同系統上。

## Cryptography

(1) 轉換資料以隱藏其資訊內容並防止其未經授權的使用或未被發現的修改。 (2) 透過將資訊轉換（加密）為不可讀的格式（稱為密文）來保護資訊。只有擁有金鑰的人才能將訊息解密（或解密）為明文。

## Customer Information Control System (CICS)

是 IBM 的線上事務處理監視器，充當作業系統和應用程式之間的介面，以提供快速的大容量線上事務處理。

## Cylinder

CKD 裝置上具有固定磁軌數的儲存單元。
