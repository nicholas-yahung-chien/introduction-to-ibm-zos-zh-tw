## Cache

記憶體用於改善指令、資料或兩者的存取時間。駐留在快取中的資料通常是駐留在速度較慢、成本較低的儲存中的其他位置（例如磁碟或另一個網路節點上）的資料的副本。

## Cache fast write

快速寫入操作的一種形式，其中儲存伺服器將資料直接寫入快取，以便稍後轉儲。

## Cache hit

當讀取操作傳送到叢集並且在快取中找到請求的資料時發生的事件。與快取未命中對比。

## Cache memory

內存，通常是易失性內存，儲存伺服器用來改善指令或資料的存取時間。高速緩衝記憶體通常比主記憶體或儲存媒體更小且更快。相同的資料除了駐留在快取中之外，還駐留在儲存系統中的儲存裝置上。

## Cache miss

當讀取操作發送到叢集，但在快取中找不到資料時發生的事件。與快取命中對比。

## Call home

儲存產品和服務提供者之間建立的通訊鏈路。當儲存產品需要服務時，可以使用此連結向 IBM 或其他服務提供者發出呼叫。透過存取機器，服務人員可以處理服務任務，例如查看錯誤日誌和問題日誌或啟動追蹤和轉儲檢索。另參見心跳與遠端技術援助資訊網路 (RETAIN)。

## Capacity Backup (CBU)

如果因緊急情況而導致伺服器容量出現不可預見的損失，則能夠將模型容量或專用引擎替換為備份伺服器。

## Capacity Upgrade on Demand (CUoD)

透過購買永久處理器或記憶體單元啟動功能，啟動選定伺服器上的附加處理器和記憶體單元。 CUoD 增加了新工作負載的容量，使伺服器能夠適應意外的效能需求。

## Cascading

1) 將網路控制器在連續的層級中相互連接，以集中比單一層級允許的更多的線路。 2) 在高可用性叢集系統多處理（HACMP）中，涉及一種系統設定，其中如果主節點發生故障，則具有特定資源的最高優先權的系統節點取得資源。當主節點重新整合到系統中時，叢集系統節點將資源讓渡給主節點。

## Cataloged procedure

作為 PDS 或 PDSE 成員儲存的過程是編目過程。包含過程的資料集可以是私有資料集或系統資料集。

## Central Processing Unit (CPU)

是電腦处理指令的主要组件。它執行作業系統和應用程式，並不斷接收來自使用者或活動軟體程式的輸入。它處理資料並產生輸出，該輸出可以由應用程式儲存或顯示在螢幕上。

## Change Mode (CMOD)

在類別UNIX作業系統中，chmod是系統和系統呼叫，它可能會改變檔案系統物件（檔案和目錄）的存取權限。

## Channel

通道子系統的一部分，用於管理通道子系統和一組控制單元之間的單一 I/O 介面。

## Channel Path Identifier (CHPID)

由通道路徑ID或CHPID表示的通道代表實際的通訊路徑。 CHPID 是促進 CPC 和外部裝置之間通訊的句柄。 CHPID 必須是唯一的，因為它表示 CPC 的唯一通訊路徑。通道子系統內允許的最大 CHPID 數量為 256。通道可以在 LPAR 之間共用。 CHPID 與實體連接埠或主機內部定義的內部連線相關聯。有效的 CHPID 的十六進位範圍是從 X'00' 到 X'FF'。

## Channel Command Word (CCW)

一條針對專用 I/O 通道處理器的指令，該處理器實際上是一個有限狀態機。它用於在通道連接的裝置上啟動 I/O 操作，例如「讀取」、「寫入」或「感測」。在實現通道 I/O 的系統架構上，通常所有裝置都透過通道連接，因此所有 I/O 都需要使用 CCW。

## Cross-cluster communication

DS8880 在 I/O 機櫃之間使用 PCIe 路徑來提供 CPC 之間的跨叢集 (XC) 通訊。此設定意味著 XC 通訊和 I/O 流量之間沒有單獨的路徑，從而簡化了拓撲。在正常操作期間，XC 通訊流量使用整體可用 PCIe 頻寬的一小部分（小於 1.7%），因此 XC 通訊流量對 I/O 效能的影響可以忽略不計。
