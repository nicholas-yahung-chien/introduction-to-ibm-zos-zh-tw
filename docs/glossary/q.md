## qcow2 (QEMU Copy On Write)

是 QEMU（託管虛擬機器監視器）使用的磁碟映像檔的檔案格式。它使用磁碟儲存最佳化策略，將儲存配置延遲到實際需要時為止。 qcow 格式的檔案可以包含各種磁碟映像，這些映像通常與特定的來賓作業系統相關聯。

## QEMU

QEMU（Quick Emulator 的縮寫）是一個免費的開源託管虛擬機管理程式，用於執行硬體虛擬化（不要與硬體輔助虛擬化混淆）。 QEMU is a hosted virtual machine monitor: it emulates CPUs through dynamic binary translation and provides a set of device models, enabling it to run a variety of unmodified guest operating systems.它還可以與 KVM 一起使用速度以接近虛擬機器的速度 x8675 x862 速度（866762 x862 x862 x8629（263 x863）一起執行虛擬機器的速度。電腦上進行硬體虛擬化擴展）。 QEMU 還可以對使用者級進程進行 CPU 模擬，允許為一種架構編譯的應用程式在另一種架構上執行。

## Quality of Service (QoS)

對所提供的服務符合客戶期望的程度進行評估。服務業務經營者經常評估提供給客戶的服務質量，以便改善服務、快速發現問題並更好地評估客戶滿意度。
