## Kernel

內核是作業系統的核心模組。它是作業系統中首先載入的部分，並且保留在主記憶體中。

## Kernel-based Virtual Machine (KVM)

是 Linux 核心的虛擬化基礎設施，可將其轉變為虛擬機器管理程式。它在2007年2月5日發布的核心版本2.6.20中被合併到Linux核心主線。 KVM需要具有硬體虛擬化擴充的處理器。參見千字節。

## Key field

計數關鍵資料記錄的第二個（可選）欄位。密鑰長度在計數欄位中指定。密鑰長度決定欄位長度。程式將資料寫入關鍵欄位並使用關鍵欄位來識別或定位給定的記錄。子系統不使用關鍵字段。

## Keyword operand (In UNIX)

關鍵字操作數是系統可以辨識的特定名稱或符號。因此，關鍵字操作數可以按照位置操作數之後的任何順序輸入。在接下來的命令描述中，關鍵字操作數以大寫字元顯示。您可以使用某些關鍵字運算元指定值。將數值括在運算元後面的括號中。

## Kilobyte (KB)

1) 對於處理器儲存、真實和虛擬儲存以及通道磁碟區，210 或 1024 位元組。 2) 磁碟儲存容量和通訊量為1000位元組。

## Korn shell

互動式命令解釋器和命令程式語言。
