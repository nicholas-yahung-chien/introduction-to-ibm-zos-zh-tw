# IBM Z 詞彙表：B

## Bandwidth

定義為在固定時間內可以傳輸的資料量。對於數位裝置，頻寬通常以每秒位數 (bps) 或每秒位元組數表示。

## Base addressing space

在擴展地址磁碟區上，該術語指地址低於 65,536 的柱面。這些柱面位址由 16 位柱面號或高 12 位零 (0) 的 28 位柱面號表示。

## Batch processing

批次用於可以通過最少的人工互動並在預定時間或根據需要執行的程式。

## Battery Service Module (BSM) set

DC-UPS 包含稱為電池服務模組 (BSM) 組的整合式電池組。 BSM 集由四個 BSM 模組組成。如果框架的外部電源遺失，BSM 集有助於保護資料。如果框架的交流輸入電源完全喪失，電池將用於維持處理器複合體和 I/O 機櫃的供電足夠的時間，以允許 NVS 記憶體的內容（尚未從快取中轉儲的修改資料）寫入處理器複合體內部的硬碟（不是儲存機櫃驅動器）。

## Bay

裝置可以實際安裝並連接到電源和資料的實體空間。例如，電源或磁碟機可以插入托架中。另參見服務邊界。

## Block

作為一個單元記錄、處理或傳輸的一串資料元素。這些元素可以是字元、單字或實體記錄。磁碟上的一組連續磁區，包含區區塊頭和一些整數記錄。儲存裝置上的所有區區塊的大小相同（固定大小）。另參見固定區區塊架構和資料記錄。

## Break Point Value (BPV)

当磁盘空间请求达到此大小或更大时，系统更愿意使用该范围的柱面管理空间。这适用于对符合柱面管理空间资格的資料集的主空间或辅助空间的每个请求。如果没有足够的柱面管理空间可用，则系统将使用磁道管理空间或使用这两个区域。斷點值以柱面表示。当磁盘空间请求的大小小于断点值时，系统优先使用磁道管理区域。如果那里没有足够的可用空间，那么系统将使用柱面管理的空间，或者将使用这两个区域。

## BSM

參見電池服務模組 (BSM) 套件。

## Business Class configuration

高密度、高效能儲存設定，包括標準磁碟機箱和高效能快閃儲存機箱，並透過最小化裝置介面卡的數量和最大化連接到每個儲存系統的儲存機箱的數量來針對成本進行最佳化和設定。
