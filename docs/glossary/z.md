# IBM Z 詞彙表：Z

[返回詞彙表索引](./)

## zDAC

參見 z/OS 發現和自動設定。

## zHPF

參見 IBM Z 的高效能 FICON。

## zKVM (KVM for IBM Z)

Linux 核心的虛擬化基礎設施，可將其轉變為虛擬機器管理程式。它簡化了伺服器虛擬化的設定和操作，利用常見的 Linux 管理技能來管理虛擬化，支援利用開源社群的靈活性和敏捷性，並提供開源虛擬化選擇。

## Zoning

在光纖通道環境中，將多個連接埠分組以形成虛擬的專用儲存網路。屬於某個區域的連接埠可以相互通信，但與其他區域中的連接埠隔離。

## zSeries File System (ZFS)

zFS 是一個 z/OS UNIX 檔案系統，可以像分層檔案系統 (HFS) 一樣使用。 zFS 檔案系統包含檔案和目錄，包括可以使用 z/OS HFS 應用程式介面 (API) 存取的存取控制清單 (ACL)。

## z/OS

適用於 IBM Z 系列產品的作業系統。

## z/OS Discovery and Auto Configuration (zDAC)

設計用於在連接到 FICON 通道時，為連接到交換器或控制器的新的和變更的磁碟和磁帶控制器自動執行多個 I/O 設定定義任務。

## z/OS Global Mirror

IBM Z 環境的遠端鏡像和複製功能。儲存伺服器的功能，可協助控製程式在另一個儲存系統上維護邏輯磁碟區的一致副本。任何附加主機對主邏輯磁碟區的所有修改均依序呈現給單一主機。然後主機在輔助邏輯磁碟區上進行這些修改。此功能以前稱為擴充遠端複製或 XRC。

## z/OS Management Facility (Z/OSMF)

是一款適用於 z/OS 的產品，可簡化、優化和現代化 z/OS 系統程式設計師的體驗

## z/TPF

z/TPF 是 IBM Z 平台上的交易處理作業系統，設計用於大量、低延遲、高可用性的交易工作負載。

## z/VM

來賓虛擬機器（Guest VM）是虛擬機器（VM）的軟體元件，是作業系統（稱為來賓作業系統）及其相關軟體和資訊的獨立實例。 VM 來賓可以是 Linux、z/OS、z/VSE 或其他 z/VM 作業系統。

## z/VSE

z/VSE 是 IBM Z 平台上的作業系統，常用於交易處理與批次工作負載，適合較小型或特定用途的大型主機環境。
