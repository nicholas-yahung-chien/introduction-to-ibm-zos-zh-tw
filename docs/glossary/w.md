# IBM Z 詞彙表：W

## Warm demotion

IBM Easy Tier 自動模式的操作。當較低層超出其最佳頻寬容量時，將一定程度活躍的資料移至較低層。

## Wavelength-Division Multiplexing (WDM)

是一種在各種紅外線 (IR) 波長的雷射光束上組合多個訊號以沿光纖介質傳輸的方法。每個雷射器均由一組獨立的訊號調製。接收端使用波長敏感濾光片，即可見光濾色片的紅外線模擬。

## WebSM (Web-based System Manager)

是一個客戶端/伺服器應用程式，為使用者提供了管理 UNIX 系統的強大介面。基於 Web 的系統管理器使用其圖形介面使使用者能夠存取和管理多台遠端電腦。

## Weight distribution area

配置儲存系統重量所需的面積。

## Workload Manager (WLM)

是 z/OS 大型主機作業系統的基本元件。它根據管理員定義的目標控制對 z/OS 上執行的工作的系統資源的存取。

## Worldwide Node Name (WWNN)

包含光纖通道連接埠的主機的唯一 64 位元識別碼。另參見全球連接埠名稱。

## Worldwide port name (WWPN)

與光纖通道介面卡連接埠關聯的唯一 64 位元識別碼。它以獨立於實現和協議的方式配置。另參見全球節點名稱。
