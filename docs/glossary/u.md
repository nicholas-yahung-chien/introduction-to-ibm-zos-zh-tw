# IBM Z 詞彙表：U

[返回詞彙表索引](./)

## UFS

UNIX 檔案系統。

## Universal Access Authority (UAA)

使用 RACF 定義的每個資料集設定檔都需要通用存取權限 (UACC)。 UACC 是 RACF 授予未在設定檔存取清單中定義的使用者和群組的預設存取權限。如果這些使用者或群組之一請求存取受設定檔保護的資料集，RACF 將根據 UACC 批准或拒絕該請求。

## Unit address

對於 IBM Z，與給定控制單元上的裝置關聯的位址。在 ESCON 介面上，單元位址與裝置位址相同。在 OMI 介面上，單元位址指定介面上的控制單元和裝置對。

## Unit Control Block (UCB)

z/OS 控制區區塊用於定義通道附加裝置。

## UNIX System Services (USS)

UNIX 系統服務 (USS) 是 z/OS 中必需的、包含的元件。 USS 是經過認證的 UNIX 作業系統實現，並針對大型主機架構進行了最佳化。

## Upper-layer protocol

支援一個或多個邏輯協定（例如，SCSI 命令協定和 ESA/390 命令協定）的 Internet 協定 (IP) 層。參見 ANSI X3.230-199x。
