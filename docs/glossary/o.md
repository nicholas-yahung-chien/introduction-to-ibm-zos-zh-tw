## Octal

八進制（Octal，源自拉丁語 octo 或“八”）是描述以 8 為基數的數字系統的術語。八進制數字系統由八個單位數字組成：0、1、2、3、4、5、6 和 7。

## OMVS

第一個實作被稱為 MVS OpenEdition（或 OE、OMVS），然後它成為 OS/390 UNIX 系統服務，最後成為我們今天所知的 z/OS UNIX 系統服務。

## OMVS command

用於呼叫 z/OS UNIX shell。主要互動式運算環境是 UNIX 系統的使用者應該會發現 z/OS UNIX shell 環境很熟悉。 OMVS 指令用於呼叫 z/OS UNIX shell。 shell 是一個命令處理器，它呼叫 shell 命令或向系統請求服務的實用程式，使用 shell 程式語言編寫 shell 腳本，並以互動方式（在前台）、後台或批量執行 shell 腳本和 C 語言程式。

## OnLine Transaction Processing (OLTP)

一類資訊系統，促進和管理導向事務的應用程式，通常用於資料輸入和檢索事務處理。 OLTP 也被用來指系統立即回應使用者請求的處理。

## OpenFlow

是一種協議，允許伺服器告訴網路交換器將資料包發送到哪裡。在傳統網路中，每個交換器都有專有軟體來告訴它該做什麼。透過 OpenFlow，資料包行動決策得以集中化，因此可獨立於各個交換器和資料中心裝置對網路進行程式設計。

## OpenStack

是一套用於建構和管理公有雲和私有雲雲運算平台的軟體工具。在一些最大的軟體開發和託管公司以及數千名個人社群成員的支持下，許多人認為 OpenStack 是雲端運算的未來。

## Open source software

開源是指原始碼（程式設計師用特定程式語言編寫程式時的程式形式）可供公眾免費使用和/或對其原始設計進行修改的程式或軟體。開源程式碼通常是作為協作努力建立的，其中程式設計師改進程式碼並在社區內共享更改。

## Open system

該系統的特性符合整個產業提供的標準，因此可以連接到符合相同標準的其他系統。適用於 DS8000 系列，此類系統是指透過 SCSI 或 FCP 協定連接到 DS8000 系列的主機。另參見小型電腦系統介面和光纖通道協定。

## Open System Adapter (OSA)

是 IBM 系統唯一的 LAN（區域網路）連線。

## Open vSwitch (OVS)

Open vSwitch 是一款生產品質的多層虛擬交換機，已獲得開源 Apache 2.0 授權的許可。它旨在透過程式擴展實現大規模網路自動化，同時仍支援標準管理介面和協定。

## Operating System (OS)

是管理電腦軟硬體資源並為電腦程式提供通用服務的系統軟體。

## Open Systems / 390: (OS/390)

是用於 System/390 IBM 大型主機的 IBM 作業系統。
