## IBM i

IBM 授權程式是 Power Systems 伺服器的整合作業系統。它整合了關聯式資料庫、安全性、Web 服務、網路和儲存管理功能等功能。 IBM i 的前身是 i5/OS，其之前是作業系統/400 (OS/400)。

## IBM (International Businesses Machine)

用於識別 IBM 儲存產品的品牌名稱，包括 DS8000 系列。另參見 DS8000 和 DS Storage Manager。

## IBM DS8000

IBM Resiliency 系列儲存伺服器和連接的儲存裝置（磁碟機模組）的成員。 DS8000 系列儲存產品提供高效能、容錯的企業資料儲存和管理，支援透過多個並發作業系統和通訊協定進行存取。多個對稱多處理器、整合快取、驅動器模組的 RAID 支援以及透過高速串行儲存架構介面的磁碟存取提供了高效能。

## IBM DS8880 Series (DS8884, DS8886, DS8888)

专为认知业务而设计和构建的全新 IBM DS8880 系列資料系统。 IBM DS8884：商务级系统。使組織能夠透過先進、易於使用的操作和執行關鍵工作負載的 24x7 可用性來克服儲存挑戰，無論是作為整合系統還是多個平台的專用平台。採用經濟實惠、靈活且節省空間的封裝形式交付。高达 256 GB 快取、64 x 16 GB 光纤通道/FICON 連接埠和最多 768 个 HDD/SSD 驱动器，以及 120 个快閃儲存卡。 IBM DS8886：企业级系统。幫助加速任務關鍵型應用程式，以 24x7 可用性和卓越功能為後盾，所有這些都以易於擴展的軟體包提供。高达 2 TB 的总系统内存、128 个 16 GB 光纤通道/FICON 連接埠和多达 1,536 个 HDD/SSD 驱动器，以及 240 个快閃儲存卡。 IBM DS8888：企业级系统。通过全快閃儲存設定，为应用程式提供关键任务效能并降低延迟，效能提升高达 4.5 倍。高达 2 TB 的总系统内存、128 x 16 GB 光纤通道/FICON 連接埠和最多 480 个快閃儲存卡。

## IBM DS CLI

與 DS8000 儲存子系統搭配使用的命令列介面 (CLI)。

## IBM DS Storage Manager (DS8000 Storage Management GUI)

具有 Web 瀏覽器介面的軟體，用於設定 DS8000 系列。

## IBM MQ

IBM MQ 是 IBM 於 1993 年 12 月首次以 IBM 產品推出的網路軟體產品家族。它最初稱為 MQSeries，並於 2002 年更名為 WebSphere MQ，加入 WebSphere 產品套件。 2014 年 4 月，它更名為 IBM MQ。 MQ 系列中包含的產品包括 IBM MQ、IBM MQ Advanced、IBM MQ Appliance 和 IBM MQ for z/OS。

## IBM Multipath Subsystem Device Driver (SDD)

IBM 軟體，為連接儲存裝置的主機系統提供多路徑設定支援。 SDD 提供增強的資料可用性、跨多個路徑的動態輸入/輸出負載平衡以及自動路徑故障轉移保護。

## IBM POWER8 Processor

POWER8 是基於 Power 架構的超標量對稱多處理器系列。 IBM 於 2014 年 6 月推出基於 POWER8 的系統。

## IBM Resiliency Family

DS8000 系列和 IBM TotalStorage 企業儲存伺服器（型號 750 和 800）上提供的一組硬體和軟體功能和產品，以及整合軟體和服務。

## IBM Spectrum Control

允許管理員從單一控制台設定、管理和監控 SAN 儲存裝置效能的介面。 IBM Enterprise Storage Server Network (ESSNet) 提供對 Enterprise Storage Server 的 Web 瀏覽器存取的專用網路。 IBM 將 ESSNet 軟體安裝在稱為 IBM TotalStorage ESS Master Console 的 IBM 工作站上，該工作站隨第一個 ESS 交付一起提供。

## IBM Z

IBM 產品系列強調接近零停機時間，包括 System z10 和 System z10s。

## ICKDSF (Device Support Facility)

z/OS ICKDSF 公用程式執行安裝、使用和維護 IBM 直接存取儲存裝置 (DASD) 所需的功能。也用於執行服務功能、錯誤檢測和介質維護。 ICKDSF 公用程式主要用於初始化磁碟區。該過程至少涉及建立磁碟標籤記錄和磁碟區內容表 (VTOC)。 ICKDSF還可以掃描磁碟區以確保其可用，可以重新格式化所有磁軌，可以寫入主位址，以及其他功能。

## ICF

參見內部耦合設施。

## ICON

代表電腦上存在的某物的圖片。

## IEBCOMPR

IEBCOMPR 是一個 z/OS 資料集實用程式，用於在邏輯記錄層級比較兩個連續資料集、兩個分區資料集或兩個擴展分區資料集 (PDSE)，以驗證備份副本。

## IEBCOPY

IEBCOPY 是一種 z/OS 資料集實用程式，用於在一個或多個分區資料集或擴展分區資料集 (PDSE) 之間全部或部分複製或合併成員。

## IEBDG

IEBDG 是一個 z/OS 資料集實用程式，用於提供測試資料模式以用作編程調試輔助工具。

## IEBGENER

IEBGENER 實用程式是一個 z/OS 複製程式，是作業系統的一部分。它用於複製順序資料集、分區資料集 (PDS) 或 PDSE 的成員。

## IEBIMAGE

IEBIMAGE 是一個 z/OS 資料集實用程式，用於建立和維護特定的印表機類型模組並將它們儲存在庫中。

## IEBPTPCH

IEBPTPCH 用於列印或打孔順序資料集或 PDSE 的全部或選定部分。

## IEBUPTE

IEBUPTE 用於建立或修改順序或分區資料集或 PDSE。

## IEFBR14

IEFBR14 是一個虛擬程式，通常在唯一需要的操作是配置或刪除資料集時插入 JCL 中。

## IEHINITT

EHINITT 是一種 z/OS 系統實用程式，用於將標準磁碟區標籤集放置到安裝在一個或多個磁帶單元上的任意數量的磁帶上。

## IEHLIST

IEHLIST 是一種 z/OS 系統實用程式，用於列出一個或多個分區資料集或 PDSE 的目錄中的條目，或索引或非索引磁碟區內容表中的條目。在程式的單次執行中可以請求任意數量的清單。

## IEHMOVE

IEHMOVE 是一個 z/OS 系統實用程式，用於移動或複製作業系統資料的邏輯集合。

## IEHPROGM

IEHPROGM 是一個 z/OS 系統實用程式，用於修改系統控制資料並在組織層級維護資料集。

## IFHSTATR

IFHSTATR 是一個系統實用程式，用於格式化和列印 Type 21 SMF（系統管理工具）記錄中的資訊。這些記錄提供按體積 (ESV) 資料進行的錯誤統計。

## IML

## Information Management System (IMS)

是一個資料庫和事務管理系統。

## Information Management System transaction manager (IMS TM)

是一個基於訊息的事務處理器。

## Information Technology (IT)

通常是在企業或其他企業的環境中使用電腦來儲存、檢索、傳輸和操作資料或資訊。

## Infrastructure as a Service (IaaS)

是雲端運算的一種形式，透過網際網路提供虛擬化運算資源。 IaaS 是雲端運算服務的三大主要類別之一，另外兩個類別是軟體即服務 (SaaS) 和平台即服務 (PaaS)。

## Initial Microcode Load (IML)

將電腦的微代碼載入到該電腦的儲存中的操作。

## Initial Program Load (IPL)

將軟體載入到電腦中的操作，通常是控制電腦的作業系統。

## Initiator

一種與一個或多個目標通訊並控制一個或多個目標的 SCSI 裝置。與目標對比。

## Inode

inode 是 Linux 和其他类 UNIX 操作系统上文件系统上的一种資料结构，它儲存除文件名和实际資料之外的所有文件資訊。資料結構是一種儲存資料以便有效使用資料的方式。

## Input/Output (I/O)

與 (a) 輸入、輸出或兩者有關，或 (b) 涉及資料輸入、資料輸出或兩者的裝置、製程或通道。

## I/O Adapter

接受輸入並產生特定格式輸出的電子電路、擴充卡或外掛模組的通用術語。該術語的「介面卡」部分意味著在輸入/輸出流和內部電腦電路之間發生資料格式和電子計時的轉換。

## Input/Output Configuration Data Set (IOCDS)

由 I/O 設定程式 (IOCP) 建置並儲存在與處理器控制器關聯的磁碟檔案上的設定定義。

## Input/Output Definition File (IODF)

由HCD（硬體設定定義）建立，包含有​​關I/O設定的資訊，例如：作業系統資料、交換器資料、裝置資料，包括EDT定義、處理器資料、分區資料、通道路徑資料、控制單元資料和通道子系統資料。

## I/O enclosure

I/O 機櫃容納轉接器並提供轉接器和處理器之間的連接。裝置轉接器和主機轉接器都安裝在 I/O 機櫃中。

## In-stream procedure

是其 JCL 語句放置在執行它們的作業中的過程。流內過程的開始必須由 PROC 語句標記，其結束由 PEND 語句標記。流內過程必須在使用之前定義，這意味著過程定義必須先於其呼叫。

## Intelligent Resource Director

智慧型資源管理器 (IRD) 是自動管理 CPU 資源和某些 I/O 資源的軟體。

## Intelligent Write Caching (IWC)

透過更好的寫入快取管理和更好的寫入順序降級來提高效能。

## Interactive mode

互動式命令模式提供歷史記錄功能，可以輕鬆重複或檢查先前的命令使用情況。登入 DS CLI 應用程式的安裝目錄，然後開始使用 DS CLI 命令和參數。

## Interactive System Productivity Facility (ISPF)

是在 IBM 大型主機上執行的 z/OS 作業系統的軟體產品。 ISPF 主要提供一組面板的 IBM 3270 終端介面。每個面板可能包括選單和對話框，用於在底層時間共享選項 (TSO) 上執行工具。 ISPF 經常用於操作來自其名為 ISPF/PDF 的程式開發工具的 z/OS 資料集，其中 PDF 指的是程式開發工具。

## Interface cards

提供儲存裝置與內部處理器和記憶體之間的連接。

## Interleave

自動在 RAID-5 陣列中的磁碟機上建立兩個條帶分區，這兩個分區都使用計數-鍵-資料 (CKD) 記錄格式。

## Internal Battery Feature (IBF)

內部電池功能 (IBF) 是許多 IBM Z 系列處理器上的選購功能。 IBF 提供本地不間斷電源，進一步增強主機中電源設計的穩健性，並提高主機對電源線幹擾的免疫。它提供電池備用電源，以便在機房所有電源斷電時保存處理器資料。 IBF 可以在停電期間短暫保持電力，或在停電時間較長時有序關閉。 IBF 在 IBM z14 Model ZR1 上不可用，這讓客戶在計劃對該機器進行新建或升級時需要考慮另一個因素。

## Internal Coupling Facility

提供一種經濟有效的方法來開始 DB2 資料共享。此外，如果 ICF 設定有內部連結，則與外部耦合設施相比可能具有效能優勢。

## Internet Protocol (IP)

在網際網路協定套件中，一種沒有連接的協議，它透過網路或互連網路路由資料，並充當較高協定層和實體網路之間的中介。上層支援一種或多種邏輯協定(例如SCSI指令協定和IBM Z指令協定)。參見 ANSI X3.230-199x。 IP 的縮寫是 TCP/IP 中的 IP。另參見傳輸控制協定/網際網路協定。

## Invalidate

從快取中刪除邏輯資料單元，因為它無法支援對裝置上的邏輯資料單元的持續存取。此刪除可能是儲存伺服器或與該裝置關聯的儲存裝置內發生故障的結果。

## I/O

## I/O Adapter (IOA)

PCI 總線上的輸入輸出轉接器。

## IOCDS

## IOCP (I/O Configuration Program)

為系統定義所有可用 I/O 裝置和通道路徑的程式。

## I/O interface

使主機能夠與其關聯的外圍裝置執行讀取和寫入操作的介面。

## Input/Output Operations Per Second (IOPS)

是對非連續儲存位置的最大讀寫次數的標準測量單位。

## I/O ports

它允許軟體驅動程式與電腦上的硬體裝置進行通訊。

## I/O Priority Manager (IOPM)

持續監控和平衡系統資源，幫助應用程式自動滿足其效能目標，無需操作員幹預。允許提高關鍵 I/O 的優先權。 IO 優先權管理器擴充了 IBM Z System WorkLoad Manager 功能以包含儲存。借助此功能，系統管理員可以使用 zWLM 來管理所有運算資源。

## I/O priority queuing

允許 DS8000 系列使用 z/OS Workload Manager 提供的 I/O 優先權資訊來管理 I/O 操作的處理順序。

## IBM Z Hypervisor Performance Manager (zHPM)

監控 KVM 上執行的虛擬機，以實現基於目標的策略的效能目標。
## IBM 3270 terminal

IBM 大型主機常見的互動式終端介面。現代使用者通常透過 3270 terminal emulator 連線到 z/OS，使用固定欄位、function key、command line 與 panel 的方式操作 TSO、ISPF、SDSF 等工具。

## ISRDDN

ISPF 提供的診斷工具，可用 `TSO ISRDDN` 或 `DDLIST` 從 ISPF command line 啟動。它可列出目前 TSO/ISPF session 的 DDNAME allocation、data set concatenation、ENQ、duplicate member/module，也可加入 APF、LINKLIST、PARMLIB、LPA 等 pseudo-ddname 來協助定位「目前 session 實際讀到哪個 library 或 member」。
