# IBM Z 詞彙表：G

[返回詞彙表索引](./)

## GB

參見千兆位元組。

## GiB

參見吉比位元組。

## GDPS

參見地理分散的平行系統綜合體。

## Geographically Dispersed Parallel Sysplex (GDPS)

是一種多站點或單一站點端應用程式可用性解決方案，提供管理遠端複製設定和儲存子系統（包括 IBM TotalStorage Enterprise Storage Server）的功能，以自動執行平行系統綜合體操作任務並從單點控制執行故障復原。 GDPS 有助於自動執行計劃內和計劃外停機的復原程式，以提供近乎連續的可用性和災難復原能力。

## Gigabyte (GB)

以 10 為基數的測量單位等於 1,000,000,000 位元組 (10^9)。使用十進制千兆位元組 (GB) 來衡量容量。二進制千兆位元組（或吉比位元組 [GiB]）用作記憶體的度量。

## Gibibyte (GiB)

以 2 為基數的測量單位等於 1,073,741,824 位元組 (2^30)。注意：GiB 用作記憶體的度量單位，也稱為二進位千兆位元組。

## Gigapack

透過光纖通道協定連接到磁碟機轉接器（在 DS8000 中），並透過 RAID 轉接器中的控制卡開關轉換為 SAS 協定。

## Global Copy

DS8000 遠端鏡像和複製功能的可選功能，可在同一個 DS8000 儲存系統或另一個 DS8000 儲存系統上維護邏輯磁碟區的模糊副本。換句話說，任何連接的主機在主邏輯磁碟區上執行的所有修改也在稍後的時間點在輔助邏輯磁碟區上執行。不嚴格保持原來的更新順序。另參見遠端鏡像和複製以及高速鏡像。

## Global Mirror

遠端鏡像和複製功能的選用功能，可提供 2 站點遠距離遠端複製。主機寫入本機儲存系統的資料會自動保存在遠端。另請參見高速鏡像和遠端鏡像和複製。

## Global Network Block Device (GNBD)

是 GFS（全域檔案系統）的基礎。

## Global Resource Serialization (GRS)

是 IBM z/OS 作業系統中的元件，負責實現對連續可重複使用運算資源（例如資料集和磁帶磁碟機）或虛擬資源（例如清單、佇列和控制區區塊）的公平存取。

## Group

在 DS8000 文件中，根據上下文，兩種不同類型群組的暱稱。另參見磁碟包或複製服務伺服器群組。

## GRUB

GNU GRUB（GNU GRand Unified Bootloader 的縮寫）是來自 GNU 專案的引導程式包。 GRUB 是自由軟體基金會的多重開機規範的參考實現，它使使用者可以選擇引導電腦上安裝的多個作業系統之一，或選擇特定作業系統分割區上可用的特定核心設定。

## Guests (VM)

來賓虛擬機器（Guest VM）是虛擬機器（VM）的軟體元件，是作業系統（稱為來賓作業系統）及其相關軟體和資訊的獨立實例。 VM 來賓可以是 Linux、z/OS、z/VSE 或其他 z/VM 作業系統。

## GUI (graphical user interface)

透過滑鼠操作圖示（圖片）和視窗與電腦進行通訊的一種方式。一種使程式更加使用者友好的裝置。
