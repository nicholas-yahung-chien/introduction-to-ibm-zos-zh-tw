# 用語審稿

這份表格用來追蹤課程常見術語的台灣繁中譯名。狀態分為：

- `draft`：初稿
- `review`：待 IBM 台灣確認
- `approved`：已確認

| English Term | zh-Hant-TW | Status | Notes |
| --- | --- | --- | --- |
| mainframe | 大型主機 | review | IBM 台灣常用譯名。 |
| operating system | 作業系統 | approved | 通用譯名。 |
| virtualization | 虛擬化 | approved | 通用譯名。 |
| Sysplex | Sysplex | review | 建議保留產品/技術名稱原文。 |
| HMC | HMC | review | 首次出現加註 Hardware Management Console。 |
| SE | SE | review | 首次出現加註 Support Element。 |
| IPL | IPL / 初始程式載入 | review | 標題可用「執行 IPL」，正文首次出現解釋全名。 |
| IOCDS | IOCDS | review | 首次出現加註 Input/Output Configuration Data Set。 |
| Crypto Express | Crypto Express | review | IBM 產品/功能名稱保留原文。 |
| transaction | 交易 | review | 視上下文可為交易、交易作業或交易處理。 |
