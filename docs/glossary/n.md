# IBM Z 詞彙表：N

[返回詞彙表索引](./)

## Name server

儲存參與的 DS8000 叢集名稱的伺服器。

## NAS

參見網路附加儲存。

## NBD

參見網路區塊裝置。

## Near-line

線上儲存（提供持續、快速的資料存取）和離線儲存（提供不頻繁的資料存取以用於備份或長期儲存）之間的一種中間儲存。

## Network Attached Storage (NAS)

是連接到電腦網路的檔案級電腦資料儲存伺服器，為異質客戶端群組提供資料存取。 NAS 專門透過其硬體、軟體或設定來提供檔案服務。

## Network Block Device (NBD)

是一個裝置節點，其內容由遠端電腦提供。通常，網路區區塊裝置用於存取實體上不在本機電腦上而是在遠端電腦上的儲存裝置。

## Network File System (NFS)

是一種客戶端/伺服器應用程式，允許電腦使用者查看並選擇性地儲存和更新遠端電腦上的文件，就像它們位於使用者自己的電腦上一樣。

## Network Interface Card (NIC)

網路介面控制器（NIC，也稱為網路介面卡、網路介面卡、LAN 介面卡或實體網路介面以及類似術語）是將電腦連接到電腦網路的電腦硬體元件。

## Network manager

用於監控、管理和診斷網路問題的一個或一組程式。

## Network Time Protocol (NTP)

是一種網路協議，用於透過資料包交換、可變延遲資料網路在電腦系統之間進行時脈同步。 NTP 於 1985 年之前開始執行，是目前使用的最古老的 Internet 協定之一。

## Node

連接在光纖通道網路中的單元。 DS8000 系列是光纖通道網路中的一個節點。

## Non-removable medium

無法新增或刪除儲存裝置的記錄媒體。

## NonVolatile Storage (NVS)

用於儲存活動寫入資料的內存，以避免斷電時資料遺失。

## NVS

參見非揮發性儲存。

## N+1 redundancy

是一種彈性形式，可在組件發生故障時確保系統可用性。組件 (N) 具有至少一個獨立的備用組件 (+1)。
