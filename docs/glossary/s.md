# IBM Z 詞彙表：S

[返回詞彙表索引](./)

## SAF

參見系統存取設施。

## SE

參見支撐元件。

## Sequential Data Set

在順序資料集中，記錄是連續儲存的資料項。

## Server Time Protocol (STP)

是在許可內碼 (LIC) 中實現的伺服器範圍設施，並向處理器資源/系統管理器 (PR/SM) 提供單一時間視圖。

## SMF

參見系統管理工具。

## Software

是電腦系統的一部分，由編碼資訊或電腦指令組成。

## Storage

也稱為記憶體，是一種由電腦組件和用於保留數位資料的記錄媒體組成的技術。它是電腦的核心功能和基本組成部分。

## STP

參見伺服器時間協定。

## Support Element (SE)

支援元件是用於監視和作業系統的專用工作站。它連接到系統的中央處理器複合體 (CPC)。支援元件與中央處理器複合體 (CPC) 位於同一框架內。如果出現硬體問題，也提供備用支援元件，以便從主要支援元件切換到備用支援元件。

## Symmetric encryption

意味著加密和解密操作使用相同的金鑰。對於使用對稱加密進行安全通訊的兩個通訊方來說，金鑰代表兩者之間的共享秘密。對稱加密通常比非對稱加密更有效，並且通常用於大量資料加密。

## System Access Facility (SAF)

是 z/OS 定義的介面，使程式能夠使用系統授權服務來控制對資源（例如資料集和 z/OS 命令）的存取。

## System Management Facilities (SMF)

用於大型電腦的 IBM z/OS 的一個元件，提供將活動記錄寫入檔案或資料集的標準化方法。

## Systems Network Architecture (SNA)

SNA 是IBM 專有的網路體系結構。它是一個用於互連電腦及其資源的完整協定堆疊。
