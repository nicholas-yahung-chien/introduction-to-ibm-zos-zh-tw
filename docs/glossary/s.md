## Systems communicate using messages transported by one of two mechanisms

耦合設施中的專用通道到通道鏈路（CTC 鏈路）和結構，僅在平行系統綜合體中可用，在標準系統綜合體中不可用。

## Subsystem data set services (DFSMSdss) utilities

DFSMSdss 是 DFSMS（資料設施儲存管理子系統）的一個元件。它用於移動和複製資料、有效管理儲存空間、備份和還原資料以及轉換資料集和磁碟區。

## SCSI

## SCSI device

使用 SCSI 協定透過 I/O 介面連接到主機的磁碟機。 SCSI 裝置可以是啟動器，也可以是目標。另參見啟動器和小型電腦系統介面。

## SCSI-FCP

光纖通道協定的同義詞，用於在開放系統主機和 DS8000 上的光纖通道介面卡之間傳輸資料的協定。另參見光纖通道協定和小型電腦系統介面。

## SDD

參見 IBM 子系統多路徑裝置驅動程式。

## SE

參見支撐元件。

## Secondary control unit

遠端鏡像和複製輔助裝置物理連接到的 DS8000。

## Secure Data Overwrite (SDO)

一種以使得資料不可讀的方式安全地覆蓋敏感資料的方法。

## Secure Hash Algorithm 3 (SHA-3)

加密雜湊演算法（或雜湊“函數”）旨在提供從二進位資料字串到固定大小的“訊息摘要”的隨機映射，並實現某些安全屬性。雜湊演算法可用於數位簽章、訊息認證碼、金鑰導出函數、偽隨機函數和許多其他安全應用

## Sector

磁碟上包含最小可尋址資訊單元的區域。格式化磁碟時，作業系統將其劃分為磁區和磁軌。磁區理論上是磁碟上可以同時讀取或寫入資料的最小區域。

## SEND command (In UNIX)

使用 SEND 指令向其他使用者發送訊息。若要接收訊息，收件人的設定檔設定必須包括 INTERCOM。

## Sequential access

一種存取媒體上資料的模式，要求儲存裝置存取媒體上的連續儲存位置。

## Sequential Adaptive Replacement Cache (SARC)

是一種快取演算法，可讓您執行不同的工作負載，例如順序工作負載和隨機工作負載，而不會相互產生負面影響。

## Sequential Data Set

在順序資料集中，記錄是連續儲存的資料項。

## Serial Attached SCSI (SAS)

全雙工。使用本机 SCSI 命令集，具有更多功能。 SAS 驱动器使用 SCSI 错误检查和报告。如果发生错误（例如出现故障或边缘的磁盘），这允许您的儲存系统从驱动器收集更丰富的資訊。 SAS 驱动器是双連接埠的，这对于双控制器机箱至关重要。

## Serial connection

一種透過中斷來源串列連接來確定中斷優先權的裝置互連方法。

## Server

向稱為客戶端的其他主機提供某些服務的主機。透過網路向一個或多個客戶端提供服務的功能單元。

## Server Time Protocol (STP)

是在許可內碼 (LIC) 中實現的伺服器範圍設施，並向處理器資源/系統管理器 (PR/SM) 提供單一時間視圖。

## Service clearance

打開維修蓋和拉出零件進行維修所需的區域。

## Service Information Message (SIM)

儲存伺服器透過 IBM Z 作業系統傳送給服務人員的訊息。

## Service personnel

泛指被授權維修 DS8880 的個人或公司。術語「服務提供者」、「服務代表」和「IBM 服務代表」是指服務人員的類型。另參見系統服務代表。

## Service provider interface (SPI)

服務定義的公用介面和抽象類別的集合。 SPI 定義了您的應用程式可用的類別和方法。

## SES

SCSI 機箱服務。

## Session

邏輯子系統內的磁碟區的集合，在建立資料的一致副本期間一起管理這些磁碟區。會話中的所有磁碟區必須將其資料成功傳輸到遠端站點，然後增量才能稱為完成。

## SFF

參見小型。

## SFI

參見儲存設施影像。

## SHA-3

參見安全哈希演算法 3。

## Shared storage

設定儲存以便多個主機可以同時存取該儲存。對於所有主機來說，儲存具有統一的外觀。存取儲存的主機程式必須對儲存裝置上的資訊具有通用模型。程式的設計必須能夠處理並發存取的影響。

## Shortwave cable

短波雷射使用的波長約為 850 nm。通常用於中長距離連接（最長 500m）。

## SIM

參見服務資訊訊息。

## Simple Network Management Protocol (SNMP)

在網際網路協定套件中，用於監視路由器和連接網路的網路管理協定。 SNMP 是一個應用層協定。有關所管理裝置的資訊定義並儲存在應用程式的管理資訊庫 (MIB) 中。另參見管理資訊庫。

## Simultaneous Multithreading (SMT)

是一種透過硬體多執行緒提高超標量 CPU 整體效率的技術。 SMT 允許多個獨立的執行線程，以更好地利用現代處理器架構提供的資源。

## Single-Byte Command Code Sets Connection (SBCON)

ESCON I/O 介面的 ANSI 標準。

## Single Point Of Failure (SPOF)

電路或系統的設計、實施或設定中的缺陷所帶來的潛在風險，其中一個故障或故障會導致整個系統停止運作。

## Single-shot mode

如果您想偶爾發出命令但不想保留已發出命令的歷史記錄，請使用 DS CLI 單次命令模式。鍵入指令時，可以使用 DS HMC 的主機名稱或 IP 位址。等待命令處理並顯示最終結果。

## Single Virtual Storage (SVS)

IBM 的作業系統。 OS/VS2 R1 被稱為 SVS（單一虛擬儲存），因為它具有單一 16 MB 虛擬位址空間。利用虛擬記憶體。

## Small Computer System Interface (SCSI)

一種標準硬體介面，使各種外圍裝置能夠相互通訊。

## Smart relay host

能夠修正電子郵件尋址問題的郵件中繼或郵件閘道。

## Small Form Factor (SFF)

2.5 吋硬碟 (HDD)。測量值代表驅動器外殼內磁碟片的近似直徑。

## SMF

參見系統管理工具。

## SMP

參見對稱多處理器。

## SMT

參見同時多執行緒。

## SNMP

參見簡單網路管理協定。

## SNMP agent

駐留在網路節點上的伺服器進程，負責與有關該節點的管理器進行通訊。節點表示為託管對象，它具有在適當的 MIB 中定義的各種欄位或變數。

## SNMP manager

執行管理應用程式或應用程式套件的管理系統。這些應用程式依賴管理資訊庫 (MIB) 物件來取得駐留在受管系統上的資訊。管理器產生對此 MIB 資訊的請求，受管系統上的 SNMP 代理程式程式會回應這些請求。請求可以是 MIB 資訊的檢索或修改。

## Software

是電腦系統的一部分，由編碼資訊或電腦指令組成。

## Solid State Drive (SSD)

是高 IOPS（每秒輸入/輸出作業數）級企業儲存裝置，針對可從進階快速存取儲存中受益的關鍵業務生產應用程式。

## Source device

雙重複製或遠端複製磁碟區對中的裝置之一。對邏輯磁碟區的所有通道指令都定向到來源裝置。來源裝置上的資料會複製到目標裝置上。另參見目標裝置。

## Space efficient volumes

節省空間的磁碟區在建立時不會佔用實體容量。當資料實際寫入磁碟區時，會配置空間。物理配置的空間量是在磁碟區上執行的資料更改量的函數。所有定義的空間高效磁碟區的總和可以大於可用的物理容量。

## Spare

DS8000 上的磁碟機可以替換故障的磁碟機。可以預先指定備用以允許自動動態備用。作為備用磁碟機呼叫的任何預先存在於磁碟機上的資料都會被動態備用複製過程破壞。

## SPI

參見服務提供者介面。

## SPOF

參見單點故障。

## SRM

參見儲存資源管理。

## SSD

參見固態硬碟。

## SSID

參見子系統識別碼。

## SSPC

參見系統儲存生產力中心。

## Staging

通常根據系統需求或使用者請求，將資料從離線或低優先權裝置移回線上或更高優先權裝置。

## Standard volume

模擬多種 IBM Z 磁碟區類型之一的磁碟區，包括 3390-2、3390-3、3390-9、3390-2（3380 磁軌模式）或 3390-3（3380 磁軌模式），方法是向主機提供與同名的本機 IBM Z 磁碟區類型提供的相同數量的柱面和容量。

## Statistical Analysis System (SAS)

是由 SAS Institute 開發的軟體套件，用於進階分析、多變量分析、商業智慧、資料管理和預測分析。

## Storage

也稱為記憶體，是一種由電腦組件和用於保留數位資料的記錄媒體組成的技術。它是電腦的核心功能和基本組成部分。

## Storage Area Network (SAN)

連接公司異質儲存資源的網路。

## Storage capacity

儲存媒體可以容納的資料量；通常以千字節、兆位元組或千兆位元組表示。

## Storage complex

由管理控制台管理的一個或多個儲存系統的設定。

## Storage device

一種實體單元，提供在給定媒體上儲存資料的機制，以便隨後可以檢索資料。

## Storage Facility Image (SFI)

儲存設施映像由兩個 LPAR 組成，儲存設施中的每個處理器複合體上各有一個。從主機的角度來看，儲存設施映像能夠執行儲存伺服器的所有功能。一個儲存設施上可以設定多個 SFI。儲存設施映像也可以稱為儲存映像。

## Storage image

儲存系統的一種分區，提供儲存伺服器與一個或多個儲存裝置的仿真，該儲存裝置向主機提供儲存能力。您可以在一個儲存系統上設定多個儲存映像。 （僅限 DS8000 系列）

## Storage pool striping

透過將資料和工作負載平均分佈在更大的佇列中，從而減少偏差和熱點，提高整體效能並減少效能管理工作量。參見旋轉範圍。

## Storage Resource Management (SRM)

是一種主動方法，用於優化儲存區域網路 (SAN) 中可用磁碟機空間的利用效率和速度。

## Storage server

管理附加儲存裝置並透過提供一個或多個邏輯子系統的功能來提供儲存裝置與主機之間的介面的實體單元。儲存伺服器可以提供儲存裝置不提供的功能。儲存伺服器具有一個或多個叢集。儲存伺服器也可以稱為檔案伺服器。

## Storage system

儲存系統可以包括用於主機連接、使用者角色身份驗證、命令列介面（CLI）、圖形使用者介面（GUI）的設施，以及通常包括獨立磁碟冗餘陣列（RAID）控制器的儲存裝置。它還可能包括使第三方管理軟體能夠監視或管理儲存裝置的代理程式程式。

## Storage unit

DS8880 基礎框架加上已安裝的擴充框架。

## STP

參見伺服器時間協定。

## Striping

一種用於磁碟陣列的資料映射技術，其中固定長度的虛擬磁碟資料位址序列以規則的旋轉模式對應到成員磁碟位址序列。

## SUBMIT command (In UNIX)

使用 SUBMIT 指令提交一個或多個批次作業以進行背景處理。

## Subordinate storage system

從主儲存系統接收指令的實體單元，在啟動全域鏡像會話時指定。從屬儲存系統形成一致性群組並執行其他全域鏡像處理。一個從儲存系統只能由一個主儲存系統控制。與主儲存系統比較。

## SubSystem IDentifier (SSID)

唯一標識電腦安裝中的邏輯子系統的數字。

## SuperPAV (Parallel Access Volume)

SuperPAV 透過支援跨多個邏輯子系統 (LSS) 使用別名裝置，擴展了先前的 HyperPAV 功能。別名裝置可用於同一 DS8000 伺服器上以及伺服器上相同路徑群組中的任何基本裝置。 SuperPAV 將能夠透過較少的整體別名裝置來維持效能，並為單一較大的磁碟區提供更大的平行性，從而提高可擴展性和效能。

## Super Zap (SZAP)

SPZAP 可以列出、對應和修改載入模組（可執行程式），或修補或修正磁碟區目錄 (VTOC)。

## Support Element (SE)

支援元件是用於監視和作業系統的專用工作站。它連接到系統的中央處理器複合體 (CPC)。支援元件與中央處理器複合體 (CPC) 位於同一框架內。如果出現硬體問題，也提供備用支援元件，以便從主要支援元件切換到備用支援元件。

## Switched fabric

一種光纖通道拓撲，其中連接埠透過交換器互連。光纖交換器還可以互連以支援單一網路上的多個連接埠。另參見仲裁環路和點對點連接。

## System Access Facility (SAF)

是 z/OS 定義的介面，使程式能夠使用系統授權服務來控制對資源（例如資料集和 z/OS 命令）的存取。

## System Management Facility (SMF)

是 IBM 大型主機 z/OS 的元件，提供將活動記錄寫入檔案的標準化方法。

## Symmetric encryption

意味著加密和解密操作使用相同的金鑰。對於使用對稱加密進行安全通訊的兩個通訊方來說，金鑰代表兩者之間的共享秘密。對稱加密通常比非對稱加密更有效，並且通常用於大量資料加密。

## Symmetric MultiProcessing (SMP)

是由共享公用作業系統和記憶體的多個處理器處理程式。在對稱（或「緊密耦合」）多處理中，處理器共享記憶體以及 I/O 匯流排或資料路徑。作業系統的單一副本負責所有處理器。

## Synchronous write

資料儲存在儲存裝置上後指示其完成的寫入操作。

## System Adapter Identification Number (SAID)

自動指派給每個 DS8000 主機介面卡以供複製服務使用的唯一識別號碼。

## System Data Mover (SDM)

與資料儲存子系統和各種進階複製服務功能互動的 DFSMS 元件，以有效地移動大量資料。當主磁碟區發生更新時，SDM 管理將這些更新複製到輔助磁碟區的過程。 SDM 確保輔助磁碟區的更新依照對主磁碟區進行更新的順序進行，從而保持序列一致性。

## System Management Facilities (SMF)

用於大型電腦的 IBM z/OS 的一個元件，提供將活動記錄寫入檔案或資料集的標準化方法。

## System Modification Program

用於在 z/OS 系統上安裝軟體和軟體變更的程式。

## System p

IBM 產品系列，強調效能，包括 System p5、eServer p5、eServer pSeries、eServer OpenPower 和 RS/6000。

## System Services Representative (SSR)

負責為IBM客戶提供基本技術服務，包括以下部分或全部服務：元件更換、小修、返廠或台架維護、裝置翻新、安裝、搬遷、停產、升級和改造等。服務通常在大容量環境中執行，可存取可交換單元和零件，需要最少（如果有）的問題確定活動。服務可以由服務呼叫管理流程來指導或作為團隊的一部分來執行。

## System Storage Productivity Center (SSPC)

IBM System Storage Productivity Center 是一個整合產品，為管理 IBM 儲存產品以及管理混合供應商儲存環境提供了一個統一的焦點。 SSPC 透過提供廣泛的設定功能來增強日常儲存管理。 System Storage Productivity Center 的使用者友善介面提供了設定儲存裝置的實用程式以及提供廣泛管理功能的增強功能。

## System x

IBM 產品系列，強調業界標準的伺服器可擴充性和自我管理伺服器技術。它包括 System x3nnn、eServer xSeries 和基於 AMD 處理器的 eServer 伺服器。

## Systems Network Architecture (SNA)

SNA 是IBM 專有的網路體系結構。它是一個用於互連電腦及其資源的完整協定堆疊。
## Search-For (ISPF)

ISPF Utilities option `3.14` 與 `3.15` 的字串搜尋工具，可在指定 data set 或 members 中搜尋文字。升級查核時常用來尋找 system symbol、LOADPARM、volume serial、dataset prefix、procedure name 或設定關鍵字。

## SuperC (ISPF)

ISPF Utilities option `3.12` 與 `3.13` 的資料比較工具，用於比較 data set、member 或文字內容差異。`3.12` 是標準比較入口，`3.13` SuperCE 提供較延伸的互動介面與 profile 能力。A/B 升級中可用來比較 RES(A) 與 RES(B) 的 PARMLIB、PROCLIB、JCL 或配置 member。
