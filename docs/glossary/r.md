# IBM Z 詞彙表：R

## RACF

參見資源存取控制工具。

## Rack Power Control (RPC) cards

管理 DS8000 電源子系統並提供控制、監視和報告功能。 RPC 卡負責接收 DC-UPS 狀態並控制 DC-UPS 功能。

## Rack Unit

縮寫為 U 或 RU，是一種定義為 1.75 英吋（44.45 毫米）的測量單位。它最常用於測量 19 英寸和 23 英寸機架框架的總高度，以及安裝在這些框架中的裝置的高度，其中框架或裝置的高度以機架單位的倍數表示。

## RAID

參見獨立磁碟冗餘陣列。 RAID 通常也擴展到廉價磁碟的冗餘陣列。另參見數組。

## RAID 5

一種 RAID，可優化經濟高效的效能，同時強調透過資料條帶化利用可用容量。 RAID 5 透過在陣列中的所有磁碟機和一個奇偶校驗磁碟機之間指派奇偶校驗，為最多兩個故障磁碟機提供容錯能力。 DS8000 系列將陣列指派給裝置介面卡對（DA 對）時，會自動保留備用磁碟機。另參見裝置介面卡、RAID 10 和獨立磁碟冗餘陣列。

## RAID 6

在出現兩個並發故障的情況下，可以繼續處理對陣列中所有虛擬磁碟的讀寫請求的任何形式的 RAID。另參見裝置介面卡、RAID 5、RAID 10 和獨立磁碟冗餘陣列。

## RAID 10

一種 RAID，透過在多個磁碟機上條帶磁碟機資料並將第一組磁碟機鏡像到同一組磁碟機上，優化高效能，同時保持最多兩個故障磁碟機的容錯能力。 DS8000 系列在將陣列指派給裝置轉接器對（DA 對）時會自動保留備用磁碟機。另參見裝置介面卡、RAID 5 和獨立磁碟冗餘陣列。

## Random access

一種存取媒體上資料的模式，要求儲存裝置存取媒體上不連續的儲存位置。

## Random Access Memory (RAM)

一種可以隨機存取的電腦記憶體；也就是說，可以存取記憶體的任何字節，而無需觸及前面的位元組。 RAM 是電腦和其他裝置（例如印表機）中最常見的記憶體類型。

## Rank

組合起來建立邏輯上連續的儲存空間的一個或多個陣列。

## RAS

參見可靠性、可用性和可維護性。

## Reboot

引導是啟動電腦的作業系統，因此重新啟動是第二次或第三次啟動電腦的作業系統。電腦崩潰後通常需要重新啟動，這意味著電腦因故障而停止工作。重新啟動允許電腦重新啟動並恢復正常工作。崩潰後，電腦在重新啟動之前將無法使用。

## Recovery Point Objective (RPO)

IT 服務中的資料可能因重大事件而遺失的最長目標期限。

## Recovery Time Objective (RTO)

災難（或中斷）後必須恢復業務流程的目標持續時間和服務級別，以避免與業務連續性中斷相關的不可接受的後果。

## RECEIVE command (In UNIX)

文件傳輸的收件者使用 RECEIVE 命令來檢索傳輸的文件並將其恢復為其原始格式。

## Reduced Instruction Set Computer (RISC)

其指令集架構 (ISA) 允許其比複雜指令集電腦具有更少的每個指令周期 (CPI)。

## Redundant Array of Independent Disks (RAID)

一種對磁碟機進行分組的方法，用於管理磁碟儲存，從而將資料與故障磁碟機隔離。

## Redundant Array of Independent Memory (RAIM)

是某些電腦的主隨機存取記憶體中的設計特徵。 RAIM 利用額外的記憶體模組和條帶化演算法來防止任何特定模組發生故障並保持記憶體系統連續運作。

## Relative Record Data Set (RRDS)

具有為 VSAM 預先定義的固定長度槽，可在其中儲存記錄。 RRDS 記錄的長度總是固定的，等於槽大小。 RRDS 中的記錄由保存該記錄的槽的相對記錄號 (RRN) 來識別。 When a new record is added to an RRDS, VSAM uses the number that you supply with the file control request.

## Reliability, Availability, and Serviceability (RAS)

是一個電腦硬體工程術語，涉及可靠性工程、高可用性和可維護性設計。採用更高等級 RAS 設計的電腦具有許多功能，可以保護資料完整性並幫助它們長時間保持可用而不會發生故障，這種資料完整性和正常執行時間是大型主機和容錯系統的特殊賣點。

## Remote I/O loop (RIO loop)

I/O 子系統透過遠端 I/O 電纜環路連接到處理器子系統。電纜環路連接到處理器子系統後部可用的連接埠。 RIO 電纜連接成環路，以便系統有兩條路徑連接到每個 RIO 電纜

## Remote Mirror and Copy

儲存伺服器的功能，不斷更新邏輯磁碟區的輔助副本以符合對主邏輯磁碟區所做的變更。主磁碟區和輔助磁碟區可以位於同一儲存伺服器上，也可以位於不同的儲存伺服器上。另參見全域鏡像、高速鏡像和全域複製。

## Remote Procedure Call (RPC)

在分散式運算中，遠端程式呼叫（RPC）是指電腦程式導致過程（子程式）在不同的位址空間（通常在共用網路上的另一台電腦上）執行，其編碼就像普通（本機）程式呼叫一樣，而無需程式設計師明確編碼遠端互動的細節。

## Reporting task commands

用於建立報告。

## Resource Access Control Facility (RACF)

為 z/OS 和 z/VM 作業系統提供存取控制和審核功能的安全系統。

## Resource Management Facility (RMF)

IBM 用於 z/OS 效能測量和管理的策略產品。它是收集 z/OS 和系統綜合體環境的效能資料以監控系統效能行為的基礎產品，並提供根據業務需求優化調整和設定系統的能力。

## REST API

REST API 定義了一組函數，開發人員可以使用 HTTP 協定（例如 GET 和 POST）執行請求並接收回應。由於 REST API 使用 HTTP，因此它們幾乎可以被任何程式語言使用且易於測試（REST API 的要求是客戶端和伺服器彼此獨立，允許使用任何語言進行編碼，並在支援壽命和演進方面進行改進）。

## Resource Group

定義資源集合並關聯一組與資源設定和管理方式相關的策略。

## RESTful API

是一種應用程式介面 (API)，它使用 HTTP 請求來 GET、PUT、POST 和 DELETE 資料。

## Restructured Extended Executor (REXX)

REXX 是 IBM 開發的一種解釋性程式語言。它是一種結構化的高級程式語言，旨在易於學習和閱讀。專有和開源 REXX 解釋器適用於各種運算平台； IBM 大型主機有編譯器。

## Revolutions Per Minute (RPM)

用於協助確定電腦硬碟上的存取時間。 RPM 是衡量電腦硬碟在一分鐘內轉了幾圈的指標。 RPM 越高，存取資料的速度就越快。

## RIO loop

參見遠端 I/O 循環。

## RISC

參見精簡指令集電腦。

## R0

參見軌道描述符記錄。

## Rotate extents

将每个磁碟區的范围成功地分布到池中的所有级别，以实现基于容量的均衡工作负载分布。參見儲存池條帶化。

## Rotate volume

與單列擴充池相比，透過輕鬆地將一組磁碟區指派到特定擴充池中的不同列，以減少仍使用基於主機的剝離方法的工作負載的設定工作量。

## RPC

參見機架電源控制卡或遠端過程呼叫。

## RPM

參見每分鐘轉數。

## RRDS

參見相對記錄資料集。

## RSA

現代電腦用來加密和解密訊息的演算法。它是一種非對稱密碼演算法。不對稱意味著有兩個不同的密鑰。這也稱為公鑰密碼術，因為其中之一可以提供給每個人。另一個密鑰必須保密。它基於這樣一個事實：找到一個整數的因子是困難的（因式分解問題）。 RSA 代表 Ron Rivest、Adi Shamir 和 Leonard Adleman，他們於 1978 年首次公開描述它。
