## RACF

參見資源存取控制工具。

## Random Access Memory (RAM)

一種可以隨機存取的電腦記憶體；也就是說，可以存取記憶體的任何字節，而無需觸及前面的位元組。 RAM 是電腦和其他裝置（例如印表機）中最常見的記憶體類型。

## RAS

參見可靠性、可用性和可維護性。

## Reliability, Availability, and Serviceability (RAS)

是一個電腦硬體工程術語，涉及可靠性工程、高可用性和可維護性設計。採用更高等級 RAS 設計的電腦具有許多功能，可以保護資料完整性並幫助它們長時間保持可用而不會發生故障，這種資料完整性和正常執行時間是大型主機和容錯系統的特殊賣點。

## Resource Access Control Facility (RACF)

為 z/OS 和 z/VM 作業系統提供存取控制和審核功能的安全系統。

## Resource Management Facility (RMF)

IBM 用於 z/OS 效能測量和管理的策略產品。它是收集 z/OS 和系統綜合體環境的效能資料以監控系統效能行為的基礎產品，並提供根據業務需求優化調整和設定系統的能力。
