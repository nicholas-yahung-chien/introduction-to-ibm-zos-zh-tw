# IBM Z 詞彙表：A

## AC

參見交流電。

## Access

1) 取得運算服務或資料。2) 在電腦安全中，主體和客體之間的一種特定類型的交互，導致資訊從一個物件流向另一個物件。

## Access-any mode

在初始設定期間可以為儲存系統設定的兩種存取模式之一。它使所有沒有定義存取設定檔的光纖通道連接主機系統能夠存取儲存系統上的所有邏輯磁碟區。透過在 DS8000 儲存管理 GUI 中為特定主機定義的設定文件，該主機只能存取配置給該主機的 WWPN 的磁碟區。另參見偽主機和全球連接埠名稱。

## Access Control Lists (ACLs)

用於控制單一使用者 (UID) 和群組 (GID) 對檔案和目錄的存取。 ACL 與權限位結合使用。

## ACK

參見確認請求和確認。

## Adaptive Multi-stream Prefetching (AMP)

一種自主、工作負載反應、自我最佳化的預取技術，可根據每個應用程式調整預取量和預取時間，以最大限度地提高系統效能。

## Adaptive Replacement Cache (ARC)

比LRU（最近最少使用）效能更好的頁面替換演算法。這是透過追蹤經常使用的頁面和最近使用的頁面以及兩者的最近驅逐歷史記錄來實現的。

## Address space

是為計算實體（例如裝置、檔案、伺服器或連網電腦）的所有可能位址所配置的記憶體量。

## Advanced Encryption Standard (AES)

是美國政府用來保護機密資訊的對稱分組密碼，並在世界各地的軟體和硬體中實施以加密敏感資料。分組密碼是一種加密文字（以產生密文）的方法，其中金鑰和演算法作為一組一次應用於資料區區塊（例如，63 個連續位元），而不是一次應用於 1 位元。

## Agent

無需使用者幹預或定期自動啟動某些服務的程式。另參見子代理程式。

## Alert

儲存系統因錯誤事件收集和分析而產生的訊息或日誌。警報表示需要採取維修措施。

## Aliases

定義供特定磁碟區使用的平行存取磁碟區 (PAV) 數量，或在啟用 HyperPAV 時，由 LSS 中的任何磁碟區所使用的平行存取磁碟區 (PAV) 數量。

## All-Flash configuration

僅支援高效能快閃儲存機箱的高效能儲存設定。

## Allegiance

對於 IBM Z 產品，在處理某些條件期間在裝置和一個或多個通道路徑之間建立的關係。另請參見隱含連屬關係和保留連屬關係。

## ALLOCATE command (In UNIX)

使用ALLOCATE指令動態配置VSAM、非VSAM和HFS資料集。

## Allocated storage

已指派給磁碟區但尚未指派的空間。與配置的儲存比較。

## Allocation method

為池內的磁碟區配置容量的方法。可能的值包括旋轉容量、旋轉磁碟區和託管。

## Alternating Current (AC)

電流的一種，其中電子流動的方向以規則的間隔或週期來回切換。電源線中流動的電流和來自牆壁插座的普通家庭用電都是交流電。美國使用的標準電流是每秒60個週期（即頻率為60赫茲）；在歐洲和世界大多數其他地區，頻率為每秒 50 個週期（即頻率為 50 Hz）。

## American National Standards Institute (ANSI)

一個私人非營利組織，成員包括私人公司、美國政府機構以及專業、技術、貿易、勞工和消費者組織。 ANSI 協調美國自願共識標準的製定

## American Standard Code for Information Interchange (ASCII)

是電腦和 Internet 上最常見的文字檔案格式。在 ASCII 檔案中，每個字母、數字或特殊字元都以 7 位元二進位數（七個 0 或 1 組成的字串）表示。定義了 128 個可能的字元。

## AMP

參見自適應多流預取。

## Another Network Block Device (ANBD)

是 2003 年相容的 NBD（網路區塊裝置）擴充。它支援多執行緒，並承諾比其前身有更好的錯誤訊息。

## Anonymous

在 DS8000 儲存管理 GUI 中，圖示上的標籤，代表儲存系統和主機之間使用光纖通道介面卡但未完全定義到儲存系統的所有連接。另參見匿名主機、偽主機和任意存取模式。

## Anonymous host

偽主機的同義詞。與匿名和偽主機對比。

## ANSI

參見美國國家標準協會。

## AOS

參見現場協助。

## APAR (Authorized Program Analysis Report)

請求修正由使用者未更改的當前版本的程式中的缺陷引起的問題。

## Application programming interface (API)

是一組用於建立軟體應用程式的例程、協定和工具。 API 指定軟體元件應如何互動以及在圖形使用者介面 (GUI) 元件進行程式設計時使用 API。

## Application Specific Integrated Circuit (ASIC)

是為特殊應用而設計的微晶片，例如特定類型的傳輸協定或手持電腦。

## Arbitrated loop

對於光纖通道連接，是一種允許一組節點互連的拓撲。另參見點對點連接和交換結構。

## ARC

參見自適應替換快取。

## Array

一種結構，包含相同資料類型的元素的有序集合，其中每個元素都可以透過其索引值或集合中的序號位置來引用。在儲存系統中，陣列是使用者指定由RAID技術管理的一組磁碟。另參見獨立磁碟冗餘陣列 (RAID)。

## Array site

一組相同的驅動器（相同的容量、速度和驅動器類別）。 DS8000 會自動預先決定陣列站點中的哪些磁碟機。陣列站點沒有預先決定的處理器節點關聯性。數組站點是用於定義數組的構建區塊。

## ASCII

參見美國資訊交換標準代碼。

## ASIC

參見專用積體電路。

## Assigned storage

配置給磁碟區和連接埠的空間。

## Assist On Site (AOS)

現場協助 (AOS) 的組件相互作用，以啟動和維持支援工程師和客戶之間的支援會話。

## Asymmetric encryption

對稱加密與非對稱加密也稱為公鑰加密，它使用一對金鑰；公鑰和私鑰。如果使用公鑰對資料進行加密，則只有相應私鑰的持有者才能解密資料，從而保證了機密性。許多「安全」的線上交易系統依賴非對稱加密來建立安全通道。例如，SSL 是一種利用非對稱加密來提供 Internet 通訊安全性的協定。非對稱加密演算法通常涉及指數運算。它們在效能方面並不輕。因此，非對稱演算法通常用於保護金鑰交換，而不是用於大量資料加密。

## Availability

系統或資源能夠執行其正常功能的程度。查看資料可用性。
## Action bar (ISPF)

ISPF panel 最上方的功能列，常見項目包含 `Menu`、`Utilities`、`Options`、`Status`、`Help`。使用者可以透過 action bar 開啟 pull-down menu，選擇與目前 panel 相關的功能。對新手來說，action bar 是在不知道命令名稱時探索功能的安全入口。
