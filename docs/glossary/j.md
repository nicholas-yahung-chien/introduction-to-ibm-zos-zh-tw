# IBM Z 詞彙表：J

## Java

是一種通用電腦程式語言，它是並發的、基於類別的、物件導向的，並且專門設計為具有盡可能少的實現依賴性。

## Java Virtual Machine (JVM)

執行編譯的 Java 程式碼（小程式和應用程式）的處理器的軟體實作。

## Job Control Language (JCL)

JCL 是批次作業用來向作業系統要求資源和服務的語言。

## Job Entry System (JES)

在 z/OS 作業系統中，JES 管理輸入和輸出作業佇列和資料。每個 JES2 處理器控制自己的作業輸入、作業排程和作業輸出處理。透過單一全域 JES3 處理器對處理進行集中控制，該處理器在其他 JES3 系統上執行作業選擇、調度和裝置配置。
