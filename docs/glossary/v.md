# IBM Z 詞彙表：V

[返回詞彙表索引](./)

## virsh

是用於管理來賓和虛擬機器管理程式的命令列介面工具。

## Virtual Ethernet Port Aggregator (VEPA)

從同一下層裝置上的一個端點到另一端點的資料會經由下層裝置傳送到外部交換器。如果該交換器支援髮夾模式，則訊框將發送回較低的裝置，並從那裡發送到目標端點。

## Virtualization

建立某物的虛擬（而非實際）版本的行為，包括虛擬電腦硬體平台、作業系統、儲存裝置和電腦網路資源。

## Virtual machine facility

一種虛擬資料處理機，在使用者看來僅供該使用者專用，但其功能是透過共享共享資料處理系統的資源來完成的。 VM/370 IBM 作業系統的替代名稱。

## Virtual Local Access Network (VLAN)

是在電腦網路的資料鏈結層中劃分和隔離的任何廣播域。 VLAN 的工作原理是將標籤應用於網路封包並在網路系統中處理這些標籤，從而建立網路流量的外觀和功能，該網路流量物理上位於單一網路上，但其行為就像在不同的網路之間分割一樣。透過這種方式，VLAN 可以使網路應用程式保持獨立，儘管它們連接到相同實體網絡，並且不需要部署多組佈線和網路裝置。

## Virtual Machine (VM)

是電腦系統的仿真。虛擬機器基於電腦體系結構並提供實體電腦的功能。

## Virtual Machine Monitor (VMM)

虛擬機器監視器是一種軟體程式，可建立、管理和治理虛擬機器 (VM)，並管理實體主機上虛擬化環境的操作。

## Virtual Memory

虛擬記憶體或虛擬儲存是作業系統的一項功能，它允許電腦透過將資料頁從隨機存取記憶體 (RAM) 暫時傳輸到磁碟儲存來彌補實體記憶體的不足。

## Virtual Private Network (VPN)

是使用公用線路（通常是 Internet）建構的網絡，用於連接到專用網路（例如公司的內部網路）。

## Vital Product Data (VPD)

唯一定義處理系統的系統、硬體、軟體和微代碼元素的資訊。

## Virtual Storage Access Method (VSAM)

VSAM 是 z/OS 作業系統中使用的一種檔案儲存存取方法。它是一種高效能存取方法，用於在大型主機中以文件形式組織資料。

## Virtual Telecommunications Access Method (VTAM)

VTAM 是為大型主機環境實現系統網路架構 (SNA) 的 IBM 子系統。 VTAM為通訊應用提供應用程式介面（API），並控制介面卡和控制器等通訊裝置。

## VM

多個 IBM 作業系統的根名稱，例如 VM/XA、VM/ESA、VM/CMS 和 z/VM。另參見虛擬機器設施。

## VMware

VMware 為虛擬化提供了不同的軟體和應用程式。它已成為業界虛擬化軟體的主要提供者之一。 VMware的產品可以分為兩個層次：桌面應用程式和伺服器應用程式。

## VMware ESXi

先前的 ESX 是 VMware 開發的企業級 1 類虛擬機器管理程式，用於部署和服務虛擬電腦。作為 1 類虛擬機器管理程式，ESXi 不是安裝在作業系統中的軟體應用程式；而是安裝在作業系統中的軟體應用程式。相反，它包含並整合了重要的作業系統元件，例如核心。

## Volume

對於IBM Z，記錄在單一記錄媒體單元上的資訊。間接地，它可以指記錄媒體本身的單位。在不可移動媒體儲存裝置上，該術語也可以間接指與磁碟區關聯的儲存裝置。當多個磁碟區以對程式透明的方式儲存在單一儲存媒體上時，這些磁碟區可以稱為邏輯磁碟區。

## Volume group

物理磁碟區或邏輯磁碟區的集合。

## Volume Table Of Contents (VTOC)

直接存取儲存裝置 (DASD) 磁碟區上的表，描述磁碟區上每個資料集的位置、大小和其他特徵。
