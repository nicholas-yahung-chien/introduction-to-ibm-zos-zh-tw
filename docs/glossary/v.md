# IBM Z 詞彙表：V

## Virtual Local Access Network (VLAN)

是在電腦網路的資料鏈結層中劃分和隔離的任何廣播域。 VLAN 的工作原理是將標籤應用於網路封包並在網路系統中處理這些標籤，從而建立網路流量的外觀和功能，該網路流量物理上位於單一網路上，但其行為就像在不同的網路之間分割一樣。透過這種方式，VLAN 可以使網路應用程式保持獨立，儘管它們連接到相同實體網絡，並且不需要部署多組佈線和網路裝置。

## Virtual Machine (VM)

是電腦系統的仿真。虛擬機器基於電腦體系結構並提供實體電腦的功能。

## Virtual Memory

虛擬記憶體或虛擬儲存是作業系統的一項功能，它允許電腦透過將資料頁從隨機存取記憶體 (RAM) 暫時傳輸到磁碟儲存來彌補實體記憶體的不足。

## Virtual Private Network (VPN)

是使用公用線路（通常是 Internet）建構的網絡，用於連接到專用網路（例如公司的內部網路）。

## Virtual Storage Access Method (VSAM)

VSAM 是 z/OS 作業系統中使用的一種檔案儲存存取方法。它是一種高效能存取方法，用於在大型主機中以文件形式組織資料。

## Virtual Telecommunications Access Method (VTAM)

VTAM 是為大型主機環境實現系統網路架構 (SNA) 的 IBM 子系統。 VTAM為通訊應用提供應用程式介面（API），並控制介面卡和控制器等通訊裝置。

## Virtualization

建立某物的虛擬（而非實際）版本的行為，包括虛擬電腦硬體平台、作業系統、儲存裝置和電腦網路資源。

## Volume

對於IBM Z，記錄在單一記錄媒體單元上的資訊。間接地，它可以指記錄媒體本身的單位。在不可移動媒體儲存裝置上，該術語也可以間接指與磁碟區關聯的儲存裝置。當多個磁碟區以對程式透明的方式儲存在單一儲存媒體上時，這些磁碟區可以稱為邏輯磁碟區。
